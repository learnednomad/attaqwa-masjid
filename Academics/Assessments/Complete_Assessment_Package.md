## MODULE-SPECIFIC ASSESSMENTS

### MODULE 1: PRE-PROPHETHOOD ASSESSMENTS

#### **Diagnostic Assessment (Pre-Module)**
Assess prior knowledge before beginning instruction

**Part A: True/False (10 points)**
1. The Arabian Peninsula had a unified government before Islam (F)
2. All Arabs were pagans before Islam (F - Hanifs existed)
3. The Ka'bah was built by Ibrahim عليه السلام (T)
4. Female infanticide was practiced by all Arab tribes (F - some tribes)
5. The Year of the Elephant occurred in 571 CE (T - approximate)

**Part B: Short Answer (10 points)**
1. What do you know about pre-Islamic Arabia?
2. Name any Arab customs you're familiar with
3. What is the Ka'bah?
4. Who was Abdul Muttalib?
5. What does "Jahiliyyah" mean?

#### **Formative Assessment Tools**

**1. Daily Comprehension Checks**
- 3-2-1 Strategy: 3 things learned, 2 questions, 1 connection
- One-Minute Papers: Summarize key concept
- Think-Pair-Share: Discuss source authenticity

**2. Weekly Hadith Authentication Exercise**
Students evaluate narrations using criteria:
- Chain of narration (isnad)
- Content analysis (matn)
- Cross-reference with Quran
- Scholar consensus

**3. Source Comparison Worksheet**
| Topic | Sealed Nectar | Ibn Kathir | Baghawi | Consensus? |
|-------|--------------|-----------|----------|------------|
| Abraha's army size | | | | |
| Prophet's birth date | | | | |
| Halimah's tribe | | | | |

### MODULE 2: REVELATION & EARLY PROPHETHOOD

#### **Summative Assessment (100 points)**

**Section A: Multiple Choice (20 points)**
Based strictly on authentic sources

1. The first revelation occurred in:
   a) Ramadan b) Shawwal c) Muharram d) Rajab
   
2. The first verses revealed were from Surah:
   a) Al-Fatihah b) Al-'Alaq c) Al-Muddaththir d) Al-Muzzammil

3. The period of revelation pause (fatrah) lasted approximately:
   a) 6 months b) 2.5 years c) 1 year d) 3 years

4. The first male adult to accept Islam was:
   a) Ali b) Abu Bakr c) Uthman d) Zayd

5. According to Ibn Kathir, the first woman to accept Islam was:
   a) Fatimah b) Aisha c) Khadijah d) Umm Salamah

[15 more questions covering all authentic details]

**Section B: Short Answer (30 points)**
Answer with source citations:

1. Describe the Prophet's ﷺ experience in Cave Hira (cite Bukhari)
2. Explain Waraqah ibn Nawfal's role (cite sources)
3. List the first 10 converts in order (per Ibn Kathir)
4. Describe the stages of prayer obligation
5. Explain the concept of "fatrah" and its wisdom
6. Detail Khadijah's رضي الله عنها support methods

**Section C: Essay Questions (30 points)**
Choose 2 of 3:

1. "Analyze the gradual nature of revelation using examples from all three sources. Why did Allah reveal the Quran over 23 years?"

2. "Compare the conversion stories of Abu Bakr, Umar, and Hamzah as narrated in authentic sources. What patterns emerge?"

3. "Evaluate the Meccan response to the Prophet's message. Use Ibn Kathir and Sealed Nectar to support your analysis."

**Section D: Primary Source Analysis (20 points)**
Examine this hadith and answer questions:

حَدَّثَنَا يَحْيَى بْنُ بُكَيْرٍ، قَالَ حَدَّثَنَا اللَّيْثُ، عَنْ عُقَيْلٍ، عَنِ ابْنِ شِهَابٍ، عَنْ عُرْوَةَ بْنِ الزُّبَيْرِ، عَنْ عَائِشَةَ أُمِّ الْمُؤْمِنِينَ، أَنَّهَا قَالَتْ أَوَّلُ مَا بُدِئَ بِهِ رَسُولُ اللَّهِ صلى الله عليه وسلم مِنَ الْوَحْىِ الرُّؤْيَا الصَّالِحَةُ

1. Identify the chain of narration
2. Evaluate the strength of this hadith
3. What does this tell us about the beginning of revelation?
4. Cross-reference with Sealed Nectar's account

### MODULE 4: HIJRAH ASSESSMENT

#### **Comprehensive Project Options (100 points)**

**Option A: Documentary Script**
Write a historically accurate documentary script about the Hijrah
- Must include 20 authentic source citations
- Cover all major events
- Include maps and timeline
- 2000-word minimum

**Option B: Comparative Analysis**
Compare Hijrah accounts across all three sources
- Create detailed comparison chart
- Identify points of agreement/difference
- Analyze why differences exist
- Present findings in academic paper

**Option C: Educational Resource**
Create teaching materials for younger students
- Age-appropriate adaptation
- Maintain historical accuracy
- Include activities and assessments
- Teacher guide with sources

**Grading Criteria:**
- Authentication (25%): Proper use of sources
- Accuracy (25%): No historical errors
- Completeness (25%): Covers all major points
- Presentation (25%): Clear, organized, engaging

### MODULE 5: MEDINAN PERIOD - BATTLES

#### **Battle Analysis Framework**

For each major battle (Badr, Uhud, Khandaq):

**1. Pre-Battle Assessment (25 points)**
- Context and causes
- Troop numbers (authenticated)
- Strategic positions
- Prophetic preparation

**2. Battle Narrative (25 points)**
- Key events chronologically
- Individual stories (authenticated only)
- Turning points
- Divine intervention aspects

**3. Post-Battle Analysis (25 points)**
- Immediate outcomes
- Long-term implications
- Lessons for Muslims
- Jurisprudential rulings derived

**4. Source Evaluation (25 points)**
- Compare battle accounts across sources
- Identify most reliable narrations
- Note scholarly disagreements
- Explain authentication methodology

## AGE-SPECIFIC INTERACTIVE ACTIVITIES

### ELEMENTARY LEVEL (Ages 6-10)

#### **Activity Set 1: Story Circles**

**The Elephant Army Story Circle**
- Teacher narrates using felt board
- Children make elephant crafts
- Act out Abdul Muttalib's prayer
- Learn Surah Al-Fil with actions

**Materials Needed:**
- Felt board and figures
- Gray paper for elephants
- Bird templates
- Audio of Surah recitation

**Assessment:**
- Retell story in own words
- Draw favorite scene
- Recite 3 verses of Surah

#### **Activity Set 2: Character Building Cards**

**Prophet's Qualities Game**
Create cards with qualities:
- As-Sadiq (Truthful) - Green cards
- Al-Amin (Trustworthy) - Blue cards
- Ar-Rahman (Merciful) - Pink cards

**How to Play:**
1. Children pick scenarios
2. Choose which quality applies
3. Act out proper behavior
4. Earn points for correct matches

#### **Activity Set 3: Timeline Train**

**Seerah Journey Train**
- Each train car = major event
- Children decorate cars
- Connect in correct order
- "Travel" through Seerah

**Simplified Events:**
1. Born in Makkah
2. Lived with Halimah
3. Became orphan
4. Received revelation
5. Moved to Madinah
6. Returned to Makkah

### MIDDLE SCHOOL LEVEL (Ages 11-13)

#### **Activity Set 1: Historical Detective**

**Source Investigation Activity**
Students receive "evidence packets":
- Historical claims about events
- Must verify using sources
- Mark as: Authentic / Weak / Fabricated
- Present findings to class

**Example Investigation:**
"The Prophet ﷺ was born circumcised"
- Check Sealed Nectar (p. 67)
- Review Ibn Kathir's analysis
- Find scholarly consensus
- Conclusion: Weak narration

#### **Activity Set 2: Debate Tournaments**

**Structured Islamic Debates**
Topics from authentic sources only:

1. "Hikmah in the Treaty of Hudaybiyyah"
   - Team A: Immediate benefits
   - Team B: Long-term wisdom

2. "Lessons from Uhud"
   - Team A: Military lessons
   - Team B: Spiritual lessons

**Debate Rules:**
- Must cite authentic sources
- Respectful Islamic etiquette
- 3-minute arguments
- 2-minute rebuttals

#### **Activity Set 3: Mapping History**

**Interactive Map Projects**
1. Trade routes of Quraysh
2. Hijrah route with stops
3. Battle locations and strategies
4. Spread of Islam by Prophet's death

**Requirements:**
- Historically accurate
- Source citations on map
- Present to younger students
- Create quiz for peers
